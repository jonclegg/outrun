# OUTRUN

An Outrun-style pseudo-3D arcade racer in a single HTML file: no libraries, no images, no audio files. Everything (road, scenery, cars, music, sound effects) is drawn or synthesised in code.

**▶ Play it: https://jonclegg.github.io/outrun/**

## Features
- Five stages that blend into each other: Coconut Beach, Desert Canyon, Alpine Pass, Sunset Strip, Neon City
- Countdown timer with checkpoint extensions, time bonus at the goal, saved high score
- Traffic that steers around other cars, off-road slowdown, and crashes that flip the car
- Synthesised engine, tyre squeal and crash sounds, plus three original synthwave tracks with a radio-style picker

## Controls
| Key | Action |
| --- | --- |
| ← / → | Steer (on the title screen: pick music) |
| ↑ | Accelerate |
| ↓ | Brake |
| Enter | Start |
| P | Pause |
| M | Mute |

Touch screens: touch the left or right edge to steer, hold anywhere to accelerate, touch the bottom-centre to brake.

## Run locally
Download `index.html` and open it in any modern browser.
